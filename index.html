Sensitive data

Secure internal data platform

Problem
A life-sciences company needed a safe way to manage highly sensitive form data from its public sites.

I built an internal web app with Laravel and Angular on an encrypted MySQL database, with Redis caching for speed.

Several sites running from one codebase, handling payments and forms.
